# Fase 4 - Capítulo 3 - Testes com Scikit-learn

Este repositório contém testes práticos realizados durante o estudo do Capítulo 3 da Fase 4 do curso de Tecnólogo em Inteligência Artificial da FIAP.

## Objetivo

Praticar o uso da biblioteca scikit-learn em Python, com foco inicial em técnicas de codificação de variáveis categóricas aplicadas a um dataset fictício de agronegócio.

## Conteúdo testado

- Criação de dataset com Pandas
- Aplicação de LabelEncoder
- Aplicação de OneHotEncoder
- Aplicação de OrdinalEncoder
- Exibição dos resultados no terminal usando print()
